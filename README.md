# Трассировка требований в образовательной деятельности

## О проекте

Данный репозиторий предназначен для описания системы документов, посредством которых образовательная организация реализует требования федеральных государственных образовательных стандартов и иных нормативных источников.

Основная задача проекта — показать, откуда возникает каждый документ образовательной организации, какую функцию он выполняет, какие требования реализует и какими документами или сведениями подтверждается его фактическое исполнение.

Репозиторий ориентирован на аналитиков, сотрудников образовательных организаций и участников разработки информационных систем в сфере образования, которым необходимо понимать взаимосвязь между нормативными требованиями и внутренними документами вуза.

## Основная идея

Образовательная программа не является изолированным документом. Она представляет собой систему взаимосвязанных документов, создаваемых образовательной организацией для реализации обязательных требований.

Центральная логика трассировки представлена следующим образом:

```mermaid
flowchart TD
    A[Нормативный источник] --> B[Требование]
    B --> C[Документ образовательной организации]
    C --> D[Детализирующий документ]
    D --> E[Фактическое исполнение]
    E --> F[Подтверждение соответствия]
    F --> G[Актуализация документов]
